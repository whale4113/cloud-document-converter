Cloud Document Converter is a browser extension that supports downloading/copying Lark Doc as Markdown.

**English** · [简体中文](./README_ZH.md)

# Install

Install Cloud Document Converter from [Chrome Web Store](https://chromewebstore.google.com/detail/cloud-document-converter/ehkomhhcinhikfddnmklbloahaakploh), [Microsoft Edge Store](https://microsoftedge.microsoft.com/addons/detail/pcjebkebnehplnpkpnhipagefaffiopp), and [Firefox Add-ons Store](https://addons.mozilla.org/addon/cloud-document-converter).

# Features

- Download Lark Doc as Markdown

- Copy Lark Doc as Markdown

  > ❗Note: The URL of the image generated by this way only has two hours of accessibility. This means that after two hours, the image resource will no longer be accessible.

- Batch download many Lark Docs as Markdown in one ZIP (extension popup → **Batch Download**)

  - **Refresh from Feishu wiki**: paste a wiki page URL and click **Refresh now**. The extension reads that page and every page under it, in sidebar order, and builds the download tree: each page becomes `001 - title`, and a page with children is followed by a folder of the same name. You see a preview of added, removed, renamed and moved pages, and the tree changes only when you click **Apply**.
  - **Refresh before each export** (off by default): if the wiki is unchanged, the export starts at once. If it changed, choose **Apply and export**, **Export current tree** or **Cancel export**.
  - Pages are matched by their wiki ID, so pages already exported in this session keep their result. Uploaded files (such as `.py` or `.pdf` attachments) are skipped and listed with links.
  - **Advanced options**, saved per wiki: pages to place before the root, title overrides, and a filter to keep only some top-level sections (numbers stay as in the full tree).
  - You need to be signed in to Feishu in the same browser. No extra permissions are requested.
